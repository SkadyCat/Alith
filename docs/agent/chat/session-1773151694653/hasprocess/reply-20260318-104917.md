## 关于 "Request failed due to a transient API error. Retrying..." 的原因

这个错误来自 **Claude API 侧**，是一种**瞬时性错误（Transient Error）**，常见原因有以下几类：

---

### 1. API 服务端临时过载 / 限流（最常见）
Claude API 的服务器在高峰期会对请求进行排队或限流。当瞬时请求量过大时，服务端会返回 5xx 错误，客户端自动重试。

### 2. 网络连接不稳定
- Clash 代理（7890）连接抖动
- 请求中途连接被重置（RST）
- DNS 解析超时

### 3. 请求超时
单次 API 请求响应时间过长（超过客户端设定的 timeout 阈值），触发重试机制。

### 4. API Key 速率限制（Rate Limit）
同一个 Key 在短时间内发出过多请求，被服务端限流，返回 429 Too Many Requests。

---

## 解决方案

| 原因 | 对策 |
|------|------|
| 服务端过载 | 客户端重试（已自动处理）✅ |
| 代理不稳定 | 切换 Clash 节点 / 检查代理连通性 |
| 超时 | 增大 timeout 参数 |
| 速率限制 | 降低请求频率 / 升级 API 计划 |

---

> **结论**：这类错误由重试机制自动处理，通常无需手动介入。如果**持续出现 10+ 次不停止**，建议检查 Clash 代理节点状态。
