# 爱丽丝回复

## 调查结论：CanvasEditor 会话异常退出原因

**根本原因**：pyagent_server.js 的自动重启逻辑只处理 code === 0（正常退出），当 Claude API 发生瞬时错误后进程以 **code = 1** 退出，不触发重启条件，导致 agent 会话彻底停止。

### 错误链路

`
Claude API 瞬时错误
  → "Request failed due to a transient API error. Retrying..."（重试 N 次）
  → 重试耗尽 → Copilot CLI 以 code=1 退出
  → pyagent_server.js close 事件：code !== 0 → 不重启 → 状态变 idle
  → 会话停止，POLL 不再运行
`

### 修复内容（pyagent_server.js）

- **新增检测**：code === 1 且 outputBuf 含 'transient API error' → 判定为 API 瞬时错误
- **延迟重启**：瞬时错误等待 **10 秒** 后自动重启（避免频繁打 API）
- **界面提示**：重启时显示 [API瞬时错误，10s 后重启 #N]
- **限制不变**：同样受 elaunchCount < 50 限制

修复已通过语法校验，热重载即时生效。
