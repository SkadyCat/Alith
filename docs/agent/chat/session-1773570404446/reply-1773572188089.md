## 调用方式（爱丽丝直接用）

`python
import requests
s = requests.Session()
s.trust_env = False  # 不走 Clash 代理
r = s.post('http://localhost:7439/tools/duckduckgo-search', json={
    "query": "你想搜索的内容",
    "max_results": 5,
    "region": "cn-zh"   # 中文结果；"wt-wt" = 全球
})
data = r.json()
for item in data['results']:
    print(item['title'], item['url'])
`
