# AI 生成 2D 动画模型综览（2024-2025）

用 DuckDuckGo 搜了一圈，整理如下 👇

---

## 🔥 开源可本地部署

| 模型 | 定位 | 亮点 |
|------|------|------|
| **AnimateDiff** | 文字/图像 → 动画 | ICLR 2024 Spotlight；SD 插件，ComfyUI 支持 |
| **AnimateAnyone v2** | 单张角色图 → 驱动动画 | 阿里出品，ICCV 2025；支持环境感知 |
| **MimicMotion** | 动作/姿态迁移 | 与 AnimateDiff 联用效果好；保留服装细节 |
| **ToonCrafter** | 卡通帧插值补间 | 专为手绘/卡通风格；关键帧自动补间 |
| **LivePortrait** | 面部表情驱动 | 快速推理；2D 角色面部动画 |
| **Wan2.1（万象）** | T2V/I2V 视频生成 | 阿里 2025 年开源，ComfyUI 原生支持 |

## 💡 商业平台（不想部署直接用）

- **DomoAI** — 专为视频转 2D 动漫风格设计
- **MiniMax Hailuo 02** — 全球排名 #2 AI 视频，1080P 高质
- **Runway ML** — 老牌视频生成，动画风格支持好
- **LTX Studio** — AI Anime 生成器

## 当前最推荐组合

> **AnimateDiff + AnimateAnyone v2 + ComfyUI**
> - AnimateDiff 负责文字生成动画帧
> - AnimateAnyone 负责角色一致性驱动
> - ComfyUI 串联整个工作流
