## 已完成

### 1. 独立服务 (端口 8333)
- 路径：`application/game-animation-service/`

- 与主服务完全独立，不依赖 7439 的任何代码

### 2. 动画系统 ✨
`tools/pixel_art_gen.py` 已全面升级，支持：

| 动画类型 | 帧数 | 帧延迟 | 说明 |
|---------|------|--------|------|
| idle（待机）  | 2帧 | 500ms | 轻微上下浮动 |
| walk（行走）  | 4帧 | 150ms | 腿部交替移动 |
| run（奔跑）   | 4帧 | 100ms | 快速奔跑循环 |
| attack（攻击）| 3帧 | 120ms | 攻击动作 |

- 输出格式：**动态 GIF**（可直接下载使用）
- 同时提供每帧 PNG 单图预览（帧缩略图条）

### 3. UI 功能
- 6种角色类型（战士/法师/弓手/机器人/幽灵/僵尸）
- 4种动画类型切换
- 帧缩略图条（点击查看单帧）
- 下载 GIF / PNG、生成变体、复制 Prompt
