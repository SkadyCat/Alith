好问题！这套动画用的是 **程序化骨骼动画（Procedural Skeletal Animation）**，不是龙骨/Spine 那种关键帧编辑器。原理如下：

## 🦴 核心：正向运动学（Forward Kinematics）

角色身体由「骨骼树」描述，每根骨骼有：
- 相对父骨骼的 **旋转角度**
- **长度**

子关节位置 = 父关节位置 + sin/cos(骨骼角度) × 骨骼长度

`
髋部 → 大腿 → 小腿 → 脚
脊椎 → 胸腔 → 颈部 → 头
              ↘ 上臂 → 前臂 → 手
`

## 🌊 驱动：正弦波程序化

没有关键帧！每帧直接用数学公式计算骨骼角度：

`js
// 走路动画示例
bones.thighLAngle = Math.sin(t * 3) * 0.55;    // 左腿前后摆动
bones.armRAngle   = -Math.sin(t * 3) * 0.5;    // 右臂反向摆动
bones.bodyY       = Math.abs(Math.sin(t*3)) * -3; // 身体上下弹跳
`

## 🎨 渲染：Canvas 2D 几何体拼接

不是贴图！全部用 Canvas API 画：
- **四肢** = 粗线段（lineTo + lineWidth）
- **头/身体** = 圆形 + 圆角矩形
- **眼睛/腮红** = 小椭圆

## 为什么「奇怪」？

| 问题 | 原因 |
|------|------|
| 关节处有缺口 | 四肢是线段，没做关节填充 |
| 动作太机械 | 正弦波比关键帧曲线生硬 |
| 比例不协调 | 简化的几何体，不是精细骨骼 |

---

**如果要更自然**，需要改用：
1. **缓动曲线（Easing curves）** 替代纯正弦波  
2. **圆角骨骼渲染**（在关节处画圆填充）
3. **次级动效（Secondary motion）**：头发、衣服的惯性延迟
