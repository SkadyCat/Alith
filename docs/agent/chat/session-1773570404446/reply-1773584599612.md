抱歉之前走偏了。现在已经实现原始需求：

## 🎭 http://localhost:8333/char — AI角色 → 2D骨骼动画

### 完整流程
1. **输入**: 文字描述角色（或选预设）
2. **生成**: 调用本地 **waiIllustriousSDXL_v160**（CUDA GPU）生成全身角色图
3. **去背**: **rembg** 自动去除背景，得到透明 PNG
4. **骨骼动画**: Canvas 将角色图分为 7 个骨骼区域（头/颈/躯干/腰/大腿/小腿/脚），各区域独立变换

### 动画系统
- 💤 **待机**: 重心起伏 + 呼吸缩放
- 🚶 **行走**: 髋部旋转 + 腿部交替 + 头部摆动
- 🏃 **奔跑**: 前倾 + 大幅腿部摆动
- ⚔️ **攻击**: 前冲/刺出动作
- ⬆️ **跳跃**: 完整抛物线 + 身体压缩/拉伸
- 速度可调节（0.3× — 3×）

### 注意
- 首次点击生成会加载 SDXL 模型（约 30-60 秒），后续生成很快
- 没有 Civitai API key，用本地同等质量的 SDXL 模型代替

关于"Civitai 模型"：如果你有 Civitai API key，告诉我，可以接入在线模型；否则本地 waiIllustriousSDXL 生成效果相当。
