已修复两个问题：

## 🐛 问题1：生成了三个头
**原因**: 提示词里有 character sheet，SDXL 把它理解为三视图角色参考表（正面/侧面/背面）。
**修复**: 重写了提示词工程：
- 前缀改为 solo, single character, T-pose, facing forward, front view, centered
- 负向提示新增：character sheet, reference sheet, turnaround, multi-view, multiple heads, extra heads, 2heads, 3heads, collage, grid

## 🐛 问题2：动画看不出效果  
**原因**: 骨骼变换数值太小（最大 1.5px 偏移），肉眼无法察觉。
**修复**: 全部放大 4-8×：
- **待机**: 垂直抖动 ±6px（原 ±1.5px）+ ±3% 宽度呼吸
- **行走**: 腿部旋转 ±30°（原 ±15°）、脚步抬高 8px
- **奔跑**: 身体前倾 -12°、腿部旋转 ±45°、脚步抬高 12px
- **攻击**: 身体前冲 ±18px、头颈跟随
- **跳跃**: 垂直位移 ±70px（原 ±40px）、蹲伸 squash/stretch

## ✨ 新功能：直接加载本地图片
不想等 SDXL 生成？点击 **"📁 或直接加载本地图片"** 可以直接选一张角色图（任意格式），立即套用骨骼动画。
