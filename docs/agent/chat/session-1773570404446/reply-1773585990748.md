**错误原因**：MotionAdapter 加载时没有应用 float16，导致 group_norm 收到 Float32 张量，而 pipeline 期望 Half(float16)。

**修复**：
1. dapter = adapter.to(dtype=torch.float16) — 加载后强制转型
2. pipe = pipe.to(device, dtype=dtype) — 整个 pipeline 统一 dtype  
3. pipe.upcast_vae() — 生成时 VAE 用 float32（避免 VAE decode 精度问题）
