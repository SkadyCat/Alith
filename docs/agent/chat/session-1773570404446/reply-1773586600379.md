你说得对，AnimateDiff 生成的是电影视频，不是游戏精灵动画。

## ✅ 正确方案：http://localhost:8333/sprite

**工作原理（游戏行业标准方法）：**
1. SDXL 生成**精灵图集**（sprite sheet）—— 横向排列的多帧连续动作图
2. 自动切割成逐帧 PNG（透明背景）
3. Canvas 逐帧播放，FPS 可调
4. 下载的 PNG 帧可直接导入 Unity / UE / Godot 等游戏引擎

**支持动作：**
⚔️ 攻击 / ✨ 技能 / 💤 待机 / 🚶 行走 / 🏃 奔跑 / 💢 受击 / 💀 死亡 / 🔮 施法

**支持风格：**
🟫 像素 / 🌸 动漫 / 🎨 卡通 / ⚡ 写实

**输出：**
- 每帧单独 PNG（透明背景，可直接用）
- 完整精灵图集 PNG
- 可下载 / 可上传 COS
