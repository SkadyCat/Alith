## 🔑 核心改进：每帧单独生成 + 关键帧提示词

**旧方法（错的）**：让 SDXL 生成一张宽图，"希望"它自己分格 → SDXL 不理解帧序列概念，结果乱

**新方法（正确）**：
- 每个动作定义 N 个**关键帧 pose**，每帧有专属提示词
- 每帧**单独生成**一张正方形图
- 固定 seed 保证同一角色造型一致性
- 最后拼接成图集

## 攻击动作的关键帧示例：
| 帧 | 提示词 |
|---|---|
| 1 | 攻击蓄力，武器举过头顶，侧身站姿 |
| 2 | 挥剑中段，武器斜45度，身体旋转 |
| 3 | 击中瞬间，武器全伸，随势动作 |
| 4 | 回势，回归防守站姿 |

## 优势：
- ✅ 每帧是完整的 256×256 图，质量最好
- ✅ seed 可复用：生成好的角色 seed 下次可以继续生成其他动作
- ✅ 悬停帧缩略图可看到每帧的关键帧描述
