已修复！问题原因找到了：

## 🐛 根本原因

旧的"去白色背景"用的是简单像素阈值 (R>230 → 透明)，如果角色有浅色皮肤、白色盔甲、金色头发，这些区域也会被删掉，导致角色消失。

## ✅ 修复内容

1. **换用 rembg 神经网络抠图** — 自动识别"前景角色"，不管角色是白色、浅色还是透明感都能正确保留
2. **Canvas 棋盘格背景** — 可以清楚看到哪些区域是透明的（深色棋盘 = 透明区域）

重新生成试试 → **http://localhost:8333/sprite**
