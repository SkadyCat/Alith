那个 Civitai 图用的是 **Wan Video**（Wan2.1 视频模型），已经集成进来了！

## ✅ 新增：http://localhost:8333/wan

**用了哪个模型：**
- Civitai 图：Wan2.1-I2V-14B（image-to-video，云端运行，14B参数需 ~84GB 显存）
- 我们本地：**Wan2.1-T2V-1.3B**（text-to-video，1.3B参数，~5GB显存，完全够用）

**为什么不用 14B？**  
I2V-14B 光 transformer 就 61GB fp16，加上 T5 文本编码器总共 84GB，RTX 4080 SUPER 的 17.2GB 装不下。

**如何使用：**
1. 打开 http://localhost:8333/wan
2. 用**英文**描述角色和动作（如： warrior knight attacking, anime style, white background）
3. 点击生成 → **首次运行自动下载模型 (~27GB)，之后约 30-60秒**
4. 下载 GIF 使用

> 首次下载通过 Clash 代理（7890端口），速度会很快。
